# Лабораторная работа №18
## Обработка матрицы с использованием модульной структуры

### Условие
Дана квадратная матрица n x n, 1 <= n <= 10.
1. Найти сумму элементов побочной диагонали, которые делятся на 3.
2. Все элементы ниже побочной диагонали заменить суммой цифр числа, вычисленной рекурсивной функцией `sumDigits`.

### Структура проекта
- `include/matrix_io.h`, `src/matrix_io.cpp` — ввод, вывод и создание демонстрационной матрицы.
- `include/math_utils.h`, `src/math_utils.cpp` — рекурсивная сумма цифр и проверка делимости на 3.
- `include/matrix_processor.h`, `src/matrix_processor.cpp` — обработка матрицы.
- `src/main.cpp` — главная программа.
- `CMakeLists.txt` — настройка сборки.
- `tests/test_cases.txt` — тестовые случаи.

### Важные условия
Побочная диагональ задаётся индексами `j = n - 1 - i`.
Элементы ниже побочной диагонали удовлетворяют условию `i + j > n - 1`.
Для отрицательного числа функция `sumDigits` складывает цифры его модуля: например, `sumDigits(-25) = 7`.

### Запуск в Visual Studio
1. Распаковать архив.
2. Открыть Visual Studio.
3. Выбрать **File → Open → Folder** и указать папку `lab18_matrix`.
4. Visual Studio обнаружит `CMakeLists.txt` и настроит проект.
5. Выбрать конфигурацию сборки и запустить `Lab18Matrix`.

Если Visual Studio не поддерживает CMake-проекты, создать пустой проект C++ и добавить все четыре `.cpp` и три `.h` файла, сохранив структуру каталогов.
